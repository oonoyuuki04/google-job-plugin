# Google Job Posting プラグイン

WordPress求人情報をGoogleしごと検索（Google for Jobs）に自動連携するWordPressプラグインです。

## 概要

このプラグインは、WordPress上の求人情報をGoogleしごと検索に最適化された構造化データ（JSON-LD）として自動的に出力します。求人情報を投稿するだけで、Googleの検索結果に求人情報が表示されやすくなります。

## 主な機能

- カスタム投稿タイプ「求人情報」の追加
- **Google for Jobs対応のJSON-LD構造化データの自動生成**
  - 上位表示を最適化した構造化データ出力
  - アピールポイントを先頭に配置
  - 詳細な求人情報を含む説明文
- 求人情報に必要なフィールドの管理
  - 職種
  - **アピールポイント・特徴**（上位表示に重要）
  - **お仕事内容の詳細**（専用フィールド）
  - 雇用形態
  - 給与情報
  - 勤務地
  - 交通アクセス
  - 就業時間・就業日
  - その他コメント
- タクソノミー（カテゴリー）機能
  - 雇用形態
  - 職種
  - エリア
- 管理画面での構造化データプレビュー
- Googleリッチリザルトテストへの直接リンク

## インストール方法

### 手動インストール

1. このプラグインのフォルダ全体を `/wp-content/plugins/` ディレクトリにアップロードします
2. WordPress管理画面の「プラグイン」メニューからプラグインを有効化します
3. 「求人設定」→「設定」から会社情報を設定します

### 必要要件

- WordPress 5.0以上
- PHP 7.2以上

## 使い方

### 1. 初期設定

1. WordPress管理画面から「求人設定」→「設定」にアクセス
2. 会社名、会社URL、会社ロゴを設定
3. 設定を保存

### 2. 求人情報の投稿

1. 「求人情報」→「新規追加」をクリック
2. 求人のタイトルと詳細を入力
3. 必要な情報を各セクションに入力：
   - **求人詳細情報**: 職種、雇用形態、掲載終了日
   - **お仕事内容**: 具体的な業務内容を詳しく記載（重要）
   - **アピールポイント・特徴**: 求人の魅力を記載（検索結果で目立つように表示）
   - **給与情報**: 給与範囲、通貨、給与単位
   - **勤務地情報**: 郵便番号、都道府県、市区町村、番地、交通アクセス
   - **勤務スケジュール**: 就業日、就業時間
   - **追加情報**: その他コメント、リモートワーク可否
4. 求人を公開

### 3. 上位表示のためのベストプラクティス

Googleしごと検索で上位表示されやすくするために：

1. **アピールポイント・特徴**を必ず入力
   - 「未経験歓迎」「駅近」「残業少なめ」など、求職者が検索しそうなキーワードを含める
   - 福利厚生や職場環境の魅力を記載

2. **お仕事内容**は詳細に記載
   - 具体的な業務内容を100文字以上で記載
   - 必要なスキルや経験を明記

3. **給与情報**は明確に
   - 給与範囲（最低〜最高）を設定
   - テキスト表示用にも分かりやすく記載

4. **勤務地情報**を正確に
   - 都道府県、市区町村、番地まで正確に入力
   - 交通アクセスは最寄り駅からの時間も記載

5. **掲載終了日**を設定
   - 古い求人が表示されないように期限を設定

### 4. 構造化データの確認

公開した求人ページで、以下の方法で構造化データを確認できます：

1. 求人編集画面の右サイドバーにある「構造化データプレビュー」から「リッチリザルトテスト」をクリック
2. または、「JSON-LDを表示」ボタンで生成されたJSON-LDを確認
3. [Google リッチリザルト テスト](https://search.google.com/test/rich-results)で求人ページのURLをテスト

## 構造化データの仕様

このプラグインは、Googleの[JobPosting構造化データ](https://developers.google.com/search/docs/appearance/structured-data/job-posting)の仕様に準拠したJSON-LDを生成します。

### 必須フィールド
- タイトル（職種名）
- 詳細（仕事内容）
- 掲載日
- 会社情報（会社名、URL）
- 勤務地

### 推奨フィールド
- 雇用形態
- 給与情報
- 掲載終了日
- リモートワーク可否

## カスタマイズ

### フィルターフック

構造化データをカスタマイズするためのフィルターフックを提供しています：

```php
// 構造化データをカスタマイズ
add_filter('gjp_structured_data', function($structured_data, $post_id) {
    // カスタム処理
    return $structured_data;
}, 10, 2);
```

## トラブルシューティング

### 構造化データが表示されない

1. 求人が「公開」状態になっているか確認
2. ブラウザのページソースを表示し、`<script type="application/ld+json">`タグが出力されているか確認
3. キャッシュプラグインを使用している場合は、キャッシュをクリア

### Googleに表示されない

1. Google Search Consoleで「URL検査」ツールを使用
2. リッチリザルトテストで構造化データのエラーがないか確認
3. Googleのクロールには時間がかかる場合があります（数日〜数週間）

## よくある質問

**Q: 既存の求人情報を移行できますか？**
A: はい。既存の投稿を「求人情報」投稿タイプに変更し、必要なカスタムフィールドを設定してください。

**Q: 複数の勤務地を設定できますか？**
A: 現在のバージョンでは1つの勤務地のみサポートしています。複数の勤務地がある場合は、それぞれ別の求人として投稿してください。

**Q: 掲載終了日は必須ですか？**
A: いいえ、オプションです。ただし、設定することをお勧めします。
