# Google Job Posting プラグイン

**既存のWordPress求人サイト**をGoogleしごと検索（Google for Jobs）に自動連携するプラグインです。

## 概要

このプラグインは、**既存のカスタム投稿タイプ `jobs` で管理されている求人情報**から、Googleしごと検索に最適化された構造化データ（JSON-LD）を自動的に生成・出力します。

既存の求人サイトにプラグインをインストールするだけで、Googleの検索結果に求人情報が表示されやすくなります。

## 主な機能

- **既存の `jobs` カスタム投稿タイプから自動的に構造化データを生成**
- **Google for Jobs対応のJSON-LD構造化データの自動出力**
  - 上位表示を最適化した構造化データ
  - アピールポイントを先頭に配置
  - 詳細な求人情報を含む説明文
- **既存カスタムフィールドの自動解析**
  - 職種（投稿タイトルまたはカスタムフィールド）
  - アピールポイント・特徴（コメントフィールド）
  - お仕事内容
  - 雇用形態（日本語→Google形式に自動変換）
  - 給与情報（テキストから金額を自動抽出）
  - 勤務地（住所テキストを自動分割）
  - 交通アクセス
  - 就業時間・就業日
  - 期間
- **柔軟なフィールドマッピング機能**
  - 既存フィールド名を設定するだけで対応可能
- 会社情報設定（会社名、URL、ロゴ）

## インストール方法

### 必要要件

- WordPress 5.0以上
- PHP 7.2以上
- **既存の `jobs` カスタム投稿タイプが存在すること**

### 手動インストール

1. このプラグインのフォルダ全体を `/wp-content/plugins/google-job-posting/` ディレクトリにアップロードします
2. WordPress管理画面の「プラグイン」メニューからプラグインを有効化します
3. **重要**: フィールドマッピングの設定（下記参照）
4. 「求人設定」→「設定」から会社情報を設定します

## 使い方

### 1. フィールドマッピングの設定（重要）

プラグインを有効化したら、まず既存のカスタムフィールド名を調査して設定する必要があります。

詳細な手順は [README-SETUP.md](README-SETUP.md) を参照してください。

**簡易手順**:
1. `includes/class-gjp-field-mapper.php` を開く
2. `get_field_mapping()` 関数内の `fields` 配列を既存のフィールド名に合わせて更新
3. 保存

例：
```php
'fields' => array(
    'job_title' => '',              // 空の場合は投稿タイトルを使用
    'employment_type' => 'koyou',    // 既存の雇用形態フィールド名
    'salary' => 'kyuyo',             // 既存の給与フィールド名
    'location' => 'kinmuchi',        // 既存の勤務地フィールド名
    'access' => 'kotsu',             // 既存の交通アクセスフィールド名
    'work_days' => 'shugyoubi',      // 既存の就業日フィールド名
    'work_hours' => 'jikan',         // 既存の就業時間フィールド名
    'job_content' => 'naiyou',       // 既存のお仕事内容フィールド名
    'appeal_points' => 'comment',    // 既存のコメントフィールド名
    'period' => 'kikan',             // 既存の期間フィールド名
),
```

### 2. 会社情報の設定

1. WordPress管理画面から「求人設定」→「設定」にアクセス
2. 会社名、会社URL、会社ロゴを設定
3. 設定を保存

### 3. 自動的に構造化データが出力されます

設定完了後、既存の求人ページに自動的にJSON-LD構造化データが出力されます。
新しく求人を投稿する必要はありません。

### 3. 上位表示のためのベストプラクティス

Googleしごと検索で上位表示されやすくするために：

1. **アピールポイント・特徴**を必ず入力
   - 「未経験歓迎」「駅近」「残業少なめ」など、求職者が検索しそうなキーワードを含める
   - 福利厚生や職場環境の魅力を記載

2. **お仕事内容**は詳細に記載
   - 具体的な業務内容を100文字以上で記載
   - 必要なスキルや経験を明記

3. **給与情報**は明確に
   - 給与範囲（最低〜最高）を設定
   - テキスト表示用にも分かりやすく記載

4. **勤務地情報**を正確に
   - 都道府県、市区町村、番地まで正確に入力
   - 交通アクセスは最寄り駅からの時間も記載

5. **掲載終了日**を設定
   - 古い求人が表示されないように期限を設定

### 4. 構造化データの確認

公開した求人ページで、以下の方法で構造化データを確認できます：

1. 求人編集画面の右サイドバーにある「構造化データプレビュー」から「リッチリザルトテスト」をクリック
2. または、「JSON-LDを表示」ボタンで生成されたJSON-LDを確認
3. [Google リッチリザルト テスト](https://search.google.com/test/rich-results)で求人ページのURLをテスト

## 構造化データの仕様

このプラグインは、Googleの[JobPosting構造化データ](https://developers.google.com/search/docs/appearance/structured-data/job-posting)の仕様に準拠したJSON-LDを生成します。

### 必須フィールド
- タイトル（職種名）
- 詳細（仕事内容）
- 掲載日
- 会社情報（会社名、URL）
- 勤務地

### 推奨フィールド
- 雇用形態
- 給与情報
- 掲載終了日
- リモートワーク可否

## カスタマイズ

### フィルターフック

構造化データをカスタマイズするためのフィルターフックを提供しています：

```php
// 構造化データをカスタマイズ
add_filter('gjp_structured_data', function($structured_data, $post_id) {
    // カスタム処理
    return $structured_data;
}, 10, 2);
```

## トラブルシューティング

### 構造化データが表示されない

1. 求人が「公開」状態になっているか確認
2. ブラウザのページソースを表示し、`<script type="application/ld+json">`タグが出力されているか確認
3. キャッシュプラグインを使用している場合は、キャッシュをクリア

### Googleに表示されない

1. Google Search Consoleで「URL検査」ツールを使用
2. リッチリザルトテストで構造化データのエラーがないか確認
3. Googleのクロールには時間がかかる場合があります（数日〜数週間）

## よくある質問

**Q: 既存の求人情報を移行できますか？**
A: はい。既存の投稿を「求人情報」投稿タイプに変更し、必要なカスタムフィールドを設定してください。

**Q: 複数の勤務地を設定できますか？**
A: 現在のバージョンでは1つの勤務地のみサポートしています。複数の勤務地がある場合は、それぞれ別の求人として投稿してください。

**Q: 掲載終了日は必須ですか？**
A: いいえ、オプションです。ただし、設定することをお勧めします。
